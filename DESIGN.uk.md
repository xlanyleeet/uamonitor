# Дизайн ArtList → UAMonitor

Дата: 27 жовтня 2026. Робота виконана лише у копії `uamonitor-go`.

Джерело: [ArtList.dev](https://github.com/Wojtazzzz/ArtList.dev), commit `9687d78e586cf8a89e0296c92e19a6d82363f74a`.
Збережено MIT-повідомлення: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), повна ліцензія доступна на `/licenses/artlist-MIT.txt`.

## Адаптовано

- Нейтральні світла/темна палітри, типографіка, навігація, рамки й чергування рядків таблиці.
- Каталог із пошуком за назвою/IP/версією, фільтрами стану, сортуванням та сторінками по 20 серверів.
- Профіль `/server/:id`: стан, адреса, версія, час перевірки, пік і графік онлайн за 24 години, опис, посилання спільноти, iframe-код.
- Посилання на випадковий сервер із перевагою свіжих online-спостережень.
- Компактна embed-картка `/s/:id`, сумісна з поточними iframe URL.
- Сторінки про проєкт, пояснення додавання серверів і помилок, порожні результати пошуку та порожній каталог.
- Мобільні CSS-режими на 1100/760/400 px; клавіатурний фокус, skip-link, aria-sort, підписи кнопок і фільтрів.

React-компоненти перевтілено у Svelte. Go API, PostgreSQL-схема, polling і формат JSON залишилися сумісними. Нових UI/chart runtime-залежностей не додано. Бренд і тексти — UAMonitor українською; сторонні рекламні, аналітичні та реєстраційні механізми не переносилися.

## Перевірки

- Docker frontend build: `svelte-check` — 0 errors, 0 warnings; production build успішний.
- 4 автоматичні тести: пошук/сортування/стани/адреси, SSR bulk-запити, профіль, embed, random redirect, 400/404/503.
- У браузері перевірено обидві теми, пошук із одним результатом, offline-фільтр, профіль з добовим графіком, Markdown після гідратації, dialog із правильним iframe ID та embed-картку.
- Тестовий HTML `<img onerror>` видалено санітайзером: у DOM опису немає img. Горизонтального переповнення у перевіреному desktop-профілі немає.
- Мобільні CSS-режими реалізовано; окремий browser viewport/device run у цьому етапі не проводився.
- Тимчасові записи для візуального QA створювалися через `node deploy/design-fixtures.mjs add`; після перевірки видалені командою `remove`. Скриншоти із заповненим каталогом містять лише синтетичні тестові дані.

Запуск: `docker compose -p uamonitor-go up -d --build`, сайт http://127.0.0.1:9013.
Додавання справжніх серверів і резервні копії — у [README.md](README.md). Публічного endpoint реєстрації немає: кнопка «Додати сервер» відкриває відповідну інструкцію.
